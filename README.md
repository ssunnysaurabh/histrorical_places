# Historical Places

A responsive static website showcasing historical places using **HTML and CSS**.

## Features
- Multi-page layout
- Historical-place content and imagery
- About and contact pages
- Responsive presentation

## Tech Stack
HTML5 · CSS3

## Run Locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Note
The repository name is retained for compatibility with the existing GitHub URL; the project itself is presented as **Historical Places**.
